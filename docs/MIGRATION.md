# 迁移与开发主线

## 主线

从 2026-11-22 起：

- **发布版** `D:\prompt-workbench-release` 是开发主线。
- **本地自用版** `D:\prompt-workbench` 归档，不再加新功能，只作为回退备份。
- 不再同时维护两套高级界面；新功能只进发布版。

## 已迁移数据

从本地版 `D:\prompt-workbench\data` 迁入：

- 历史记录
- 导入工作流登记
- Lucifie 触发词
- 模型、底模、工作流、模式、输出目录、自动选 LoRA 偏好

保留发布版自己的：

- `%APPDATA%\PromptWorkbench\config.json`
- 简洁模式设置

迁移前备份在：

`%APPDATA%\PromptWorkbench\migration-backup-<时间>\`

## 代码

本地版没有独有函数；发布版已经包含本地版全部功能，并增加了：

- 简洁模式
- 统一 LLM 客户端
- 模型中心
- 模型指南
- 历史删除
- 首次环境设置
- 配置驱动路径

因此没有把本地版的硬编码路径搬回发布版。

## 以后怎么用

日常使用桌面快捷方式：

`提示词工作台 发布版 - 启动`

本地版保留但不再作为主线。不要把两边的历史文件混用。
