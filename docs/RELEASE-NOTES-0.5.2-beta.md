# 本地出图工作台 0.5.2-beta

Windows 本地出图工作台：用 Ollama 写提示词，用 ComfyUI 出图。

## 本版重点

- 随机提示词库：12 类 112 条精选 + 模板组合 + 混合模式
- SFW / NSFW 两套独立随机库
- 随机提示词自动匹配风格和已安装底模；未安装只显示推荐
- 角色主题随机：角色 / 姿势 / 风格 LoRA 组合，同底模限制，最多 3 层
- 角色可保存服装套组；随机到该角色时优先使用
- 服装、场景、表情、光线、镜头、氛围、道具、天气、季节、配色、构图组件
- 组件与 LoRA 均区分 SFW / NSFW
- 画幅选择会真正写入宽高
- 角色/姿势/风格 LoRA 可标通用、仅 SFW、仅 NSFW
- 软件内快捷键弹窗、更新日志、使用说明
- 任务/服务状态、模型缓存、原子写入、诊断日志

## 下载

- 便携版：`local-image-workbench-0.5.2-beta-portable.zip`
- 不要求另装 Python
- 仍需 ComfyUI、Ollama 和模型文件

## 说明

- 不包含模型权重
- 导入的 ComfyUI 工作流保留自己的参数；内置工作流才使用参数面板
- 代码签名只有钩子，没有证书，SmartScreen 仍会提示未知发布者
- 0.3.0-beta 仍保留为较早的稳定回滚点
