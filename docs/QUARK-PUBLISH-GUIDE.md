# 夸克网盘发布教程

这份教程只讲“你作为发布者，怎么把包传到夸克并生成分享链接”。界面可能随版本调整，按钮名称以实际页面为准。

## 一、先准备三个包

建议分开：

- `本地出图工作台-0.2.0-runtime.zip`：运行时/离线环境
- `本地出图工作台-0.2.0-models-sfw.zip`：SFW 选配模型
- `本地出图工作台-0.2.0-models-nsfw.zip`：NSFW 选配模型

每个包单独算 SHA256，并把结果写进发布页。

不要：

- 把 NSFW 包和主运行包放在同一个分享链接里
- 把用户数据、API Key、未授权模型打进去
- 只放一个 exe，不放说明和校验值

## 二、登录夸克网页版

1. 浏览器打开 `https://pan.quark.cn`
2. 用手机号/夸克账号登录
3. 进入“我的网盘”或“全部文件”

## 三、新建发布文件夹

1. 点“新建文件夹”
2. 建议命名：`本地出图工作台-0.2.0`
3. 进入这个文件夹
4. 运行包、SFW 包、NSFW 包分别建子文件夹，例如：
   - `runtime`
   - `models-sfw`
   - `models-nsfw`

不要把包直接散放在“全部文件”根目录。

## 四、上传文件

1. 点“上传文件”或“上传文件夹”
2. 选择要上传的 zip
3. 大文件建议用夸克客户端上传，网页上传中断后不好续
4. 等上传完成，确认文件大小与本地一致
5. 如果文件超过单包限制，按 2GB 分卷，并让用户全部下载后再解压

上传期间不要关闭浏览器或客户端。

## 五、创建分享链接

1. 回到 `本地出图工作台-0.2.0` 文件夹
2. 勾选这个文件夹，或进入子文件夹勾选文件
3. 点“分享”
4. 选择分享方式：
   - 需要长期有效：选长期或按页面允许的最长时间
   - 需要控制传播：设置提取码
5. 点“创建分享链接”
6. 点“复制链接”或“复制分享信息”

建议三个独立链接：

- 运行包链接：公开
- SFW 包链接：公开
- NSFW 包链接：单独放，单独写 18+ 提示

不要把三个包塞进一个分享链接后再让用户自己找。

## 六、把链接写进发布页

推荐格式：

```text
夸克补充下载（不是 GitHub 镜像）：

运行包：
[链接] 提取码：[如有]

SFW 模型包：
[链接] 提取码：[如有]

NSFW 模型包（仅限 18+）：
[链接] 提取码：[如有]

SHA256：
[每个包的哈希]
```

同时写明：

- 先保存到自己的网盘，再从自己的网盘下载
- 大文件建议用夸克客户端
- 解压后先校验 SHA256
- 便携版仍需要 ComfyUI/Ollama/模型

## 七、自己先测试一遍

发布前用无痕窗口或另一台设备：

1. 打开分享链接
2. 不登录时页面是否正常
3. 登录后能否“保存到网盘”
4. 保存后能否在“我的文件”找到
5. 下载后 zip 是否完整
6. SHA256 是否一致
7. 解压后 exe 是否能启动

## 八、更新包时

1. 不要删旧链接后直接换新链接，除非发布页同步更新
2. 最好在原文件夹替换文件，保持分享链接不变
3. 更新版本号和 SHA256
4. 在发布页写“旧包已替换，请重新下载”
5. 大版本更新时另建文件夹，避免用户下到一半文件被替换

## 九、常见问题

**上传很慢**

用夸克客户端；检查网络；大文件不要用网页上传。

**分享按钮灰色**

可能文件正在上传、审核中，或账号/空间状态异常；等上传完成再试。

**别人打开链接看不到文件**

检查分享是否过期、提取码是否正确、文件是否被移出分享文件夹。

**下载后解压失败**

通常是下载不完整或分卷缺失；重新下载并核对 SHA256。

**NSFW 包被清理**

夸克有平台内容审核。不要把 NSFW 包放在主分享里；单独链接也不能保证长期存在，需准备备用分发方式。
