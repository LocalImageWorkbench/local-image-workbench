# 本地出图工作台 0.5.4-beta

Windows 本地出图工作台：用 Ollama 写提示词，用 ComfyUI 出图。

## 本版重点

- 修复简洁模式白色结果画布高度为 0、看起来仍是空白的问题
- 预览画布最小高度 340，生成图 1/2/4 张自动铺入
- 点击预览图直接打开原图
- 0.5 系列宣传片同步发布

## 下载

- 便携版：`local-image-workbench-0.5.4-beta-portable.zip`
- 不要求另装 Python
- 仍需 ComfyUI、Ollama 和模型文件

## 说明

- 不包含模型权重
- 代码签名只有钩子，没有证书，SmartScreen 仍会提示未知发布者
- 演示片为 BGM + 字幕，无配音
