# 记忆功能现状

发布版有“记录型记忆”，没有跨对话的 AI 语义记忆。

## 会记住

- 历史记录：每次生成的描述、正向/负向提示词、模型、底模、模式、LoRA
- 设置：LLM 模型、目标底模、工作流、SFW/NSFW、输出目录、自动选 LoRA
- 简洁模式：上次选择的风格、张数、简洁/高级模式
- 导入工作流登记
- Lucifie 触发词

数据位置：

`%APPDATA%\PromptWorkbench\`

## 不会记住

- 不会把历史记录自动塞进下一次 LLM 上下文
- 不会记住“这个角色叫某某”这类长期人物设定
- 不会跨机器同步
- 不会云端备份

每次生成仍然是独立的 system prompt + 本次描述。

## 历史记录的用途

历史记录可以：

- 单击选中
- 双击载入左侧
- 单条删除
- Ctrl/Shift 多选批量删除
- Ctrl+A 全选

删除只删历史记录，不删图片和提示词库文件。

## 后续可做

如果要真正的 AI 记忆，需要新增：

- 人物/项目档案
- 常用风格与负面词
- 可开关的“把偏好注入提示词”
- 本地加密存储
- 隐私清理入口

这些还没有实现。
