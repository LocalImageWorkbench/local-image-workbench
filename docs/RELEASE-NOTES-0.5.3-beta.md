# 本地出图工作台 0.5.3-beta

Windows 本地出图工作台：用 Ollama 写提示词，用 ComfyUI 出图。

## 本版重点

- 简洁模式结果区改为白色预览画布
- 无结果时显示空状态和使用提示
- 生成后 1/2/4 张图自动缩放铺入
- 点击预览图可直接打开原图
- 结果画布随窗口尺寸自动重排

## 下载

- 便携版：`local-image-workbench-0.5.3-beta-portable.zip`
- 不要求另装 Python
- 仍需 ComfyUI、Ollama 和模型文件

## 说明

- 不包含模型权重
- 代码签名只有钩子，没有证书，SmartScreen 仍会提示未知发布者
