# 简洁模式

简洁模式是默认模式，目标是让用户不知道 ComfyUI、底模、LoRA、工作流也能出图。

## 首次使用

三步向导：

1. 检查显卡、显存、LLM、ComfyUI
2. 填 LoRA 根目录、输出目录、服务地址
3. 保存并进入；完整配置在“环境设置”

没有 NVIDIA 显卡时仍可手动配置，只是不显示显存推荐。

## 第一屏

- 顶部状态：LLM / ComfyUI / 底模
- 一键准备：能启动 ComfyUI 就启动，检查结果在后台刷新
- 画面描述
- 灵感：随机、人物、服装、场景、光线
- 风格卡片
- 画幅：竖图 / 方图 / 横图
- SFW / NSFW
- 底模：当前底模 + 换底模（默认折叠）
- 张数 1 / 2 / 4
- 开始生成

## 底模与显存

- 默认 Illustrious/WAI
- 五套底模：Illustrious、MOSS、Krea2、Qwen 2.1、Anima
- 启动时检测 NVIDIA 显存；AMD/Intel 显示未检测，不虚假推荐
- 风格推荐 + 显存推荐合并显示，但不强制切换
- 当前底模显存不够时，说明变红
- 缺模型时显示红色警告，可生成/复制 DSH 提示词

## 推荐包

“推荐包”检查：

- LLM 模型
- Illustrious/WAI 底模
- Illustrious LoRA 数量

缺 Illustrious 底模时可“一键补齐”：

1. 搜索 WAI-illustrious
2. 显示大小和版本
3. 二次确认后下载
4. 写回 model_files
5. 刷新状态

不会静默下载。MOSS/Krea2/Qwen/Anima 是可选底模，不是最小包必需。

## 画角色

描述框上方有“🎭 画角色 · 搜索并接入”。

流程：

1. 选择来源：默认“在线 Civitai”，也可切“本地已安装”
2. 输入角色名，优先英文/罗马音
3. 中文名会优先转成英文名、罗马音和常见拼写；英文别名没有结果时才补搜中文原文
4. 英文输入直接搜索，不调用翻译；状态栏显示实际使用的别名
5. 新角色/冷门角色本地 LLM 可能不认识，页面有提示可复制“翻译提示词”，交给 DeepSeek Harness 等联网 AI 查官方英文名
5. 看名称、底模、大小、训练词
6. 在线确认后下载；本地直接接入
7. 自动接入 LoRA，并把训练词追加到正向提示词

底模不匹配会阻止接入，并提示先切换底模。角色 LoRA 通常匹配 Illustrious/SDXL。

## 浏览器挑选

画角色窗口里有“浏览器挑选”：

- 绿色站：civitai.com，只显示 SFW
- 红色站：civitai.red，可看 NSFW
- 可生成中文名、英文名、罗马音、同音/拼写变体
- 按当前/已安装底模和关键词筛选
- 打开后由用户在 C 站自己挑选完整模型

别名生成失败时，会直接用原始关键词打开，不阻塞。

进入 `civitai.red` 前会弹出成人内容警告：该站可能包含成人内容，并非全部都是成人内容；浏览成人内容仅限 18+。

首次进入红色站前还会显示 **3 页原站截图教程**：

- 第 1 页：完整页头 + 右上角眼睛放大 + Browsing Level 菜单
- 第 2 页：眼睛位置 + 分级勾选和 Blur
- 第 3 页：Account Settings → Content Moderation 的开关

每页一张完整/局部原图、单独红框，可上一页/下一页。设置好后点“我已设置好，继续”才打开搜索页。图解只在首次自动出现，之后可在“如何显示成人内容”再次查看。

### 怎么让 C 站显示成人内容

1. 用浏览器打开 civitai.red，登录账号
2. 点右上角眼睛图标，打开 Browsing Level
3. 打开 Show mature content，按需勾选 PG / PG-13 / R / X / XXX
4. Account Settings → Content Moderation，打开 Enable mature content；不想模糊就关闭 Blur mature content
5. 刷新页面
6. 仍看不到时确认：域名是 civitai.red、已登录、年龄验证通过、Browsing Levels 已勾选

站点设置可能随版本调整；找不到时优先看右上角眼睛图标和账号设置。

浏览器下载完成后，点“下载好了 · 交给 DSH”：

- 不需要 Civitai API Key
- 可指定下载目录或已下载的 `.safetensors`
- 生成 DSH 部署提示词
- 提示用户把 C 站模型页截图一起发给 DSH
- DSH 负责找文件、校验 SHA256、检查底模、移动/备份、测试

DSH 提示词会保存到 `%APPDATA%\PromptWorkbench\dsh-browser-download.md`（点保存时）。
